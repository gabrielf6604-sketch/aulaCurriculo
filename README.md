# 📄 Currículo em HTML

Exercício acadêmico de desenvolvimento web: criação de uma página de currículo utilizando HTML.

## 🎯 Objetivo

Praticar a estruturação de conteúdo de uma página, utilizando elementos semânticos e recursos básicos de HTML para organizar informações profissionais, formação acadêmica e competências.

## 🧰 Tecnologias

- HTML5

## ▶️ Como visualizar

1. Clone o repositório:
   ```bash
   git clone https://github.com/gabrielf6604-sketch/aulaCurriculo.git
   ```
2. Abra a pasta do projeto.
3. Abra o arquivo `aula1.html` no navegador.

## 📁 Estrutura

```text
aulaCurriculo/
├── README.md
└── aula1.html
```

## 📚 Contexto acadêmico

Atividade relacionada aos estudos de Análise e Desenvolvimento de Sistemas, com foco nos fundamentos de HTML e desenvolvimento de páginas web.
